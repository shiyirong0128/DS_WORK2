# 口袋星期天

阶段：**01_风格确认**。已选定上一阶段的「口袋星期天」作为唯一设计方向，后续迭代均以当前正式文件为基础。

## 打开页面

直接双击根目录的 **[index.html](index.html)**，立即显示游戏主界面。样式、像素字体和 SVG 均已内嵌，可离线打开，无需安装依赖。

[complete.html](complete.html) 是同一风格的独立静态通关页。主界面不会自动展示或跳转到通关页。

- 保留苔绿液晶、奶油色掌机外壳、点阵字体和实体按键外观。
- 使用原来的 7 × 7 地图、5 个箱子和 5 个目标点，位置不变。
- 移动、撤销、重开和下一关按钮仅展示外观，均为禁用状态；没有游戏 JavaScript。
- 通关页仍以 48 步、18 次推动作为展示数据，未计算游戏结果。
- 正式页面没有方案总览、其他方案卡片、风格切换、方案编号或历史稿导航。

## 维护

在仓库根目录运行：

```sh
node scripts/build.mjs
node scripts/capture.mjs
```

可选本地预览：运行 `node scripts/preview.mjs`，打开 `http://127.0.0.1:4173/`。预览服务仅提供当前游戏入口和通关页，其他路径返回 404。

构建脚本仅使用 Node.js 内置模块。截图使用本机 Chrome，可通过 `CHROME_PATH` 指定可执行文件。字体仅使用本方案需要的 VT323，中文沿用系统宋体。

后续修改 `scripts/build.mjs` 和 `src/pocket.css`，重新生成根目录 HTML；不要修改或继续使用历史目录中的十方案生成器。
