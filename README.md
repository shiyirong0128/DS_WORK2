# 口袋星期天

阶段：**03_棋盘状态辨识**。「口袋星期天」为唯一设计方向，后续迭代均以当前正式文件为基础。

## 打开页面

直接双击根目录的 **[index.html](index.html)**，立即显示游戏主界面。样式、像素字体和 SVG 均已内嵌，可离线打开，无需安装依赖。

[complete.html](complete.html) 是同一风格的独立静态通关页。主界面不会自动展示或跳转到通关页。

## 本轮静态样例

| 页面 | 总箱数 | 已到位 | 展示内容 |
| --- | --- | --- | --- |
| [index.html](index.html) | 5 | 0 / 5 | 原始布局，5 个箱子均未到位 |
| [partial.html](partial.html) | 5 | 2 / 5 | 两个到位箱子、三个未到位箱子；角色站在中央目标点上 |
| [solved.html](solved.html) | 5 | 5 / 5 | 棋盘上五个箱子全部到位，保留完整棋盘供检查 |
| [complete.html](complete.html) | 5 | 5 / 5 | 独立通关结果页 |

到位箱子保留方形外轮廓，用深色箱面和浅色像素勾共同标识；未到位箱子保留浅色箱面和斜撑。角色站在目标点时，菱形目标的四角与边框在角色外侧可见。角色覆盖目标不计入“已到位”，只有箱子与目标重合才计入。

四个页面均可单独离线打开。样例不添加到正式游戏导航，也没有状态切换或移动逻辑。

- 保留苔绿液晶、奶油色掌机外壳、点阵字体和实体按键外观。
- 中文标签采用清晰的无衬线粗体，统一字重和间距，水平排版；英文、统计数字继续使用像素字体。
- 撤销、重开使用水平排列的纯图标按钮，保留无障碍名称；不显示按钮文字和“星期天，慢慢来”标语。
- 初始布局沿用原来的 7 × 7 地图、5 个箱子和 5 个目标点；所有棋盘样例共用相同的墙体与目标位置。
- 移动、撤销、重开和下一关按钮仅展示外观，均为禁用状态；没有游戏 JavaScript。
- 部分完成样例使用 11 步、2 次推动；全部完成与通关页统一使用 28 步、7 次推动。数据在构建时写入，浏览器不运行游戏逻辑。
- 正式页面没有方案总览、其他方案卡片、风格切换、方案编号或历史稿导航。

## 维护

在仓库根目录运行：

```sh
node scripts/build.mjs
node scripts/capture.mjs
```

可选本地预览：运行 `node scripts/preview.mjs`，打开 `http://127.0.0.1:4173/`。预览服务提供当前四个页面，其他路径返回 404。

构建脚本仅使用 Node.js 内置模块。截图使用本机 Chrome，可通过 `CHROME_PATH` 指定可执行文件。英文字体使用 VT323，中文优先使用系统微软雅黑，并回退到其他无衬线字体。

棋盘使用独立的地形、目标与占用状态。`src/boards.mjs` 中坐标为从 0 开始的 `[行, 列]`；统计数量由构建脚本根据静态棋盘数据生成，角色站在目标上也不会抹掉目标层。

后续修改 `scripts/build.mjs`、`src/boards.mjs` 和 `src/pocket.css`，重新生成根目录 HTML；不要修改或继续使用历史目录中的十方案生成器。
