## 00_UI确认

10 套二维推箱子静态界面。每套 HTML 同时展示游戏主界面和通关页，便于并排确认视觉方向。

**下载仓库后，双击打开 [方案目录](00_UI确认/dist/index.html)。** 不需要安装依赖、启动服务器或联网。也可以单独打开 `00_UI确认/dist/` 内任一方案 HTML；样式、像素字体和 SVG 图形都内嵌在文件中。

### 交付内容

- `00_UI确认/dist/`：10 个独立方案 HTML + 1 个方案目录 HTML。
- `00_UI确认/预览图/`：10 张 1600 × 1040 PNG，每张同时包含主界面和通关页。
- `00_UI确认/scripts/`：生成、截图与检查脚本，使用 Node.js 内置模块，无 npm 依赖。
- `00_UI确认/assets/fonts/`：开源像素字体及各自的 SIL Open Font License。
- `00_UI确认/manifest.json`：统一地图、方案信息和展示统计。
- `00_UI确认/validation.json`：离线浏览器检查记录。

### 统一约束

地图为 7 × 7，5 个箱子、5 个目标点、1 个角色；全部方案的位置完全相同。

```text
#######
# . . #
# $ $ #
#  .  #
# $$$ #
#.@.  #
#######
```

`#` 为墙、空格为地板、`$` 为箱子、`.` 为目标点、`@` 为角色。

所有移动、撤销、重开和通关页按钮都处于禁用状态，仅呈现外观。HTML 中没有 JavaScript 或游戏逻辑。主界面显示 0 步、0 次推动；通关页统一显示 **48 步、18 次推动**，作为视觉展示数据，并非计算所得。大屏并排显示两页，窄屏上下排列。

### 重新生成

在仓库根目录运行：

```sh
node 00_UI确认/scripts/build.mjs
node 00_UI确认/scripts/capture.mjs
```

截图脚本默认使用 Windows 已安装的 Chrome，也可通过 `CHROME_PATH` 环境变量指定浏览器可执行文件。浏览器使用独立临时配置并禁用联网，检查 10 套地图一致性、按钮禁用状态、通关统计、目录图片以及 390、768、1024 像素宽度下的页面溢出情况。开发期记录在被 Git 忽略的 `.qa/` 中。

可选的本地预览：`node 00_UI确认/scripts/preview-server.mjs`，随后打开 `http://127.0.0.1:4173/`。

像素英文字体来自 Google Fonts 的 Press Start 2P、VT323 和 Silkscreen，许可证保存在 `assets/fonts/`；中文使用系统黑体、宋体或楷体回退。

本仓库从 DS_WORK2 空仓库基线建立，仅包含本次新制作的内容，未导入 DS_WORK 旧稿或历史。
