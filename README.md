# 口袋星期天

阶段：**04_交互Demo实现**。沿用苔绿液晶、奶油色掌机、像素字体和水平中文标签，现已可以实际游玩。

## 直接开始

双击根目录的 **[index.html](index.html)**，打开即显示游戏主界面。无需服务器、安装或联网；字体、图形、样式和游戏脚本均已内嵌，单独复制这一个文件也能游玩。使用启用 JavaScript 的现代浏览器。

关卡沿用现有的 7 × 7 地图，含 5 个箱子与 5 个目标点。将所有箱子推到菱形目标上即可通关。

| 操作 | 键盘 | 屏幕按钮 |
| --- | --- | --- |
| 移动 | 方向键或 W / A / S / D | 十字方向键，支持鼠标和触屏 |
| 撤销 | Z 或 Backspace | ↶ |
| 重开 | R | ↻ |

- 每次有效移动增加 1 步；推动箱子时，同时增加 1 次推动。
- 不能穿墙，也不能一次推动多个箱子；受阻操作不改变棋盘、计数或撤销记录。
- 撤销恢复上一次有效移动前的角色、箱子、已到位数量和两项计数。可连续撤销，通关后也可以撤销最后一步。
- 重开恢复初始布局，步数、推动次数和撤销记录全部清空。
- 到位箱子显示深色方形箱面和浅色像素勾；角色站在目标上仍可看到菱形边框，角色不计入“已到位”。

## 通关结果

5 个箱子全部到位时，首页内自动显示本局真实步数与推动次数。可以“再玩一次”或“查看棋盘”，在已完成棋盘中也可“查看成绩”。本 Demo 只有一个关卡。

通关后的地址携带本局有效移动轨迹，刷新时重放校验并恢复成绩。浏览器允许本地存储时，同时保留最近一次成绩；[complete.html](complete.html) 会转到同目录首页的结果视图。没有有效通关记录时显示“还没有通关记录”，不展示预设分数。禁用本地存储不会影响游玩或当前结果，携带轨迹的结果地址仍可刷新恢复。

普通打开 `index.html` 会开始新局。进行中的局面不会跨刷新保存；重开或撤销会清除已保存的通关记录。

## 仓库源码与维护

| 路径 | 用途 |
| --- | --- |
| `src/boards.mjs` | 共用地形、目标、初始局面与静态样例；坐标为从 0 开始的 `[行, 列]` |
| `src/game.mjs` | 移动、推箱、撤销、重开、胜利判断及结果重放校验 |
| `src/runtime.js` | 键盘、按钮、棋盘渲染与结果视图 |
| `src/pocket.css` | 口袋星期天样式 |
| `scripts/build.mjs` | 将源码、字体和图形嵌入 HTML，生成正式入口及参考页 |
| `tests/game.test.mjs` | 游戏规则测试 |
| `scripts/browser.mjs` / `scripts/capture.mjs` | 浏览器离线交互检查与截图 |
| `validation.json` | 本轮浏览器检查结果 |
| `assets/fonts/` | VT323 像素字体及 SIL Open Font License |

在完整仓库根目录运行（不需要 npm 安装）：

```sh
node --test tests/game.test.mjs
node scripts/build.mjs
node scripts/capture.mjs
```

构建使用 Node.js 内置模块；浏览器检查需要支持原生 WebSocket 的 Node.js 22+ 与本机 Chrome，可通过 `CHROME_PATH` 指定浏览器。检查覆盖墙体与多箱阻挡、有效计数、撤销与重开、实际通关、不同路线的真实成绩、存储被禁用、单文件离线、触屏点击，以及 320 / 390 / 768 / 1440 像素宽度。

可选本地预览：运行 `node scripts/preview.mjs`，访问 `http://127.0.0.1:4173/`；结束后按 Ctrl+C 停止。直接双击首页游玩无需此服务。

修改 `src/` 与 `scripts/build.mjs` 后重新生成 HTML，不要手工编辑生成结果或继续使用历史目录中的十方案生成器。
